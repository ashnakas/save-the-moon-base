# Save the Moon Base

An interactive lunar engineering mission for young explorers.

## Solar Emergency: webcam exhibit

Play the new physical-interaction proof of concept at [Solar Emergency](https://ashnakas.github.io/save-the-moon-base/solar-emergency/). Use your hand, mouse, touch, slider, or arrow keys to aim a solar array and bring the base back to life. See [setup and demonstration notes](solar-emergency/README.md).

The original game remains at the root site URL. Both experiences are packaged as static files for free GitHub Pages hosting.
